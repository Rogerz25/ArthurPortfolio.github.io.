# Arthur Alcocer — GitHub Pages Portfolio

A responsive engineering/STEM portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — menu and scroll animations

## Publish with GitHub Pages

1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload all three website files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. Your website will appear at `https://YOURUSERNAME.github.io/`.

## Customize
Search `index.html` for:
- LinkedIn
- GitHub
- `YOUR_EMAIL@example.com`

Replace those placeholders with your real contact information.

You can also replace project descriptions and add project images later.
