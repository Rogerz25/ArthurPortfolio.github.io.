# Arthur Alcocer — NASA / Space Medicine Portfolio

### New features
- Moon replaces the old atom/orbit graphic
- Lenis smooth scrolling and anchor navigation
- Scroll reveal animations
- Moon parallax linked to scrolling
- Optional minimal looping hero video
- Responsive mobile navigation
- Dark NASA / space-medicine aesthetic

### Optional video
Place a minimal 10–15 second MP4 named `hero.mp4` beside `index.html`. The site already loads it as a subtle full-screen background. If no video is present, the site still works.

### GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and optionally `hero.mp4` to your repository. Then use Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Replace the placeholder LinkedIn, GitHub, and email links in `index.html`.

Lenis is loaded from unpkg, so the smooth-scroll library requires internet access.
